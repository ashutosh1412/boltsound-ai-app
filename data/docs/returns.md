# Returns and refunds

- You can return any BoltSound product within **30 days** of delivery for a full refund.
- The product must be in its original box with all accessories.
- After 30 days, returns are not possible, but warranty claims still are (see warranty.md).
- Refunds go back to the original payment method within 5–7 working days.
- Opened earbuds (ear tips used) can only be returned if they are faulty.
